# SETUP VS Code setup (recommended)

> [!info] Goal
> You can use Git inside VS Code (Source Control, branches, conflicts).

---

## 1) Do this now
1. Install VS Code (if needed).
2. Open a repo folder: File → Open Folder.
3. Open “Source Control” (branch icon) on the left.
4. If asked “Install Git?” → make sure Git is installed (see [[SETUP - Install Git & verify]]).

---

## 2) Recommended settings (optional)
- Auto Save (prevents “I *did* save it!” moments)
- Git: Enable Smart Commit (only if you know what it does)

---

## 3) Check
- Bottom-left shows current branch (e.g. `main`)
- Source Control shows changes when you edit files

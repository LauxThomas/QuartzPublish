## The standard workflow (memorize this)
**Clone → Branch → Edit → Add → Commit → Pull → Push → PR → (Review) → Merge**

> [!tip] Golden rule #1
> **Before you push or do bigger work:** run `pull` once.

> [!tip] Golden rule #2
> **One commit = one meaningful step** (small, finished, describable).

> [!tip] Golden rule #3
> Don’t work directly on `main`. Use feature branches.
